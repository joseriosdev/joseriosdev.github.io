# Jose Rios's Resume Website
## Go to [joseriosdev.github.io](https://joseriosdev.github.io/ "joseriosdev") to see it working

It is optimized for **[Applicant Tracking Systems](https://en.wikipedia.org/wiki/Applicant_tracking_system "a.k.a ATS")** _(ATS)_. Inspired in the need to have a Dev CV/Resume in a simple and sophisticated way.

> Built using Vanilla JS Web Components to avoid any type of dependency.

### This site includes:
- [x] ATS Optimized Resume version
- [x] Spanish and English versions
- [x] Saving as PDF
- [x] Pretty Resume version
- [x] Daily Bible Verse
- [x] Custom greedings and curious facts
- [x] Matching Pairs game

### Saving as PDF
Use the 💾 button (or `Ctrl`/`Cmd` + `P`), pick **Letter** paper, and uncheck **Headers and footers** so the browser does not stamp the page title, URL, and date onto the resume. That checkbox is a browser setting that no web page can change, but every browser remembers your choice after the first time.
